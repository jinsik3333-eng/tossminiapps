# 몽글 캐릭터 리디자인 메모

## 피드백

- 현재 100종 몽글은 한꺼번에 보면 서로 너무 비슷하다.
- 둥근 몸, 큰 눈, 작은 팔다리, 파스텔 색, 소품만 바뀌는 구조가 반복돼 “생성 변형 세트”처럼 보인다.
- 일부는 눈/입/비율이 반복되면서 귀여움보다 인형 같은 인공감, 약간의 징그러움으로 느껴질 수 있다.

## 기존 앱 레퍼런스에서 가져갈 점

### 구독 유령 친구

- 흰색 말랑 실루엣 + 단순 점눈 + 작은 미소가 부담 없다.
- 머플러/리본처럼 작은 포인트 하나만 있어도 캐릭터 기억점이 생긴다.
- 떠 있는 포즈, 손 흔드는 동작, 둥근 카드/소품이 친근하다.

### 탐정과 도둑 친구들

- 큰 머리, 짧은 팔다리, 둥근 손발의 SD 비율이 귀엽다.
- 탐정 모자/돋보기/복면처럼 역할을 바로 읽을 수 있는 소품이 좋다.
- 도둑도 무섭지 않고 장난꾸러기처럼 보여 스토리텔링이 살아난다.
- 한 장면 안에서 “쫓고 쫓기는 사건”이 보여 캐릭터가 단순 장식이 아니라 이야기를 가진다.

## 외부 레퍼런스 방향

Lazyweb에서 확인한 유사 패턴:

- Royal Match: 캐릭터/월드 디자인을 전면에 세우고, 각 캐릭터가 특정 역할과 장면을 가진다.
- Finch/Tolan/Widgetable류 모바일 화면: 마스코트가 사용자를 안내하거나 말풍선으로 말을 건다.
- Themify/Epic류 펫·버디 갤러리: 알/펫/잠금 상태를 그리드로 보여주되, 실루엣과 상태 차이를 크게 둔다.

몽글에는 “100개 캐릭터”보다 “몽글 마을의 작은 직업/사건/도움이” 쪽이 더 맞다.

## 새 아트 디렉션

키워드:

- soft 3D toy / clay / plush
- 귀여운 유령 친구 + 작은 탐정단 + 장난꾸러기 도둑단
- 점눈, 작은 미소, 통통한 볼, 짧은 팔다리
- 소품은 하나만 크게: 돋보기, 작은 가방, 별 지도, 쿠키, 우산, 열쇠, 망토 등
- 몸통만 반복하지 말고 실루엣을 다르게: 유령 꼬리, 모자, 귀, 후드, 망토, 가방, 둥근 신발
- 배경은 앱 카드와 잘 붙는 따뜻한 크림/라벤더 계열, 체크보드/문자/로고 금지

피해야 할 것:

- 큰 반짝 눈을 100종 반복
- 같은 둥근 몸에 소품만 바꾸기
- 얇은 다리/손가락, 촉수처럼 보이는 장식
- 너무 많은 얼굴 디테일, 치아, 혀, 끈적한 젤리 질감
- 텍스트, 숫자, 로고, 화폐/코인 직접 표현

## 100종 구조 제안

25개 테마 × 4 변형은 유지하되, 변형명을 “말랑/동글/포근/반짝”이 아니라 역할/상황으로 바꾼다.

예시:

1. 낮잠 팀: 졸린 유령, 베개 배달부, 꿈 지도꾼, 별잠 파수꾼
2. 우산 팀: 빗방울 안내원, 작은 우산 기사, 무지개 수리공, 구름 우체부
3. 책갈피 팀: 기록 유령, 책장 탐정, 잃어버린 페이지, 비밀 메모꾼
4. 쿠키 팀: 부스러기 도둑, 오븐 파수꾼, 쿠키 탐정, 달콤한 증거
5. 나침반 팀: 길찾기 유령, 지도 탐정, 북쪽 별친구, 미로 도우미
6. 용/유니크 팀: 아기 용 탐정, 별왕관 유령, 오로라 문지기, 전설의 몽글

희귀도 표현:

- 커먼: 일상 소품 + 작은 포즈 차이
- 레어: 역할이 보이는 복장/소품 + 표정 변화
- 에픽: 장면 소품 2개 이하 + 빛/오라
- 유니크: 실루엣 자체가 다름. 용, 왕관 유령, 오로라 망토처럼 썸네일에서도 바로 읽히게

## 샘플 생성 프롬프트 베이스

English prompt base:

Soft 3D clay toy mascot, cute friendly ghost-like helper character, big rounded head, tiny rounded hands and feet, simple dot eyes, tiny warm smile, chubby cheeks, one clear story prop, playful detective-and-thief mini story feeling, premium mobile game collectible character, warm pastel cream and lavender studio background, soft shadow, clean silhouette, readable at small mobile icon size, no text, no logo, no numbers, no currency, no watermark, not creepy, not slimy, not uncanny, not insect-like, not many eyes, not sharp teeth.

샘플 12종을 먼저 다시 뽑고 승인 후 100종 확장한다.

추천 샘플:

- 001 낮잠 유령: 작은 베개를 안은 졸린 유령
- 006 책장 탐정: 작은 모자와 돋보기
- 018 쿠키 도둑: 쿠키 조각을 든 장난꾸러기 후드 몽글
- 026 멜로디 친구: 작은 헤드폰, 둥근 음표 소품
- 034 연필 기록꾼: 연필보다 작은 메모장
- 046 반짝 증거: 별 모양 단서와 작은 망토
- 062 나침반 길잡이: 둥근 나침반 가방
- 073 캔디 배달부: 사탕 봉투를 든 통통한 친구
- 081 행운 클로버: 네잎 모자와 작은 가방
- 089 로켓 파일럿: 둥근 헬멧, 작은 로켓 배낭
- 097 아기 용 탐정: 작은 뿔과 돋보기
- 100 오로라 문지기: 왕관 유령, 부드러운 오라

## 다음 작업 순서

1. 현재 100종은 임시 유지하되, 새 샘플 12종을 별도 경로에 생성한다.
2. 샘플 컨택트시트를 만들어 모바일 크기에서 실루엣/표정/소품을 검수한다.
3. 승인된 톤으로 JSON 프롬프트 매니페스트를 갈아엎는다.
4. 100종을 재생성하고, 앱에는 최종 WebP만 연결한다.
