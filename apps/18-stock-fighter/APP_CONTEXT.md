# 18번앱: 주식 파이터

- 경로: `apps/18-stock-fighter`
- appName: `stock-fighter`
- displayName: `주식 파이터`
- dev port: `5191`
- 성격: 실제 종목/현재가 데이터/투자 판단 기능 없이 주식 용어를 배우는 90년대 아케이드풍 교육 게임

## 구현 원칙

- 앱 내부에는 실존 인물명, 회사명, 상표명, 특정 정치 문구를 넣지 않는다.
- 파이터는 가상 암시형 이름과 픽셀 실루엣으로 표현한다.
- 광고 보상은 실제 보상형 광고 완료 이벤트가 있을 때만 지급한다.
- 로컬/미연동 환경에서는 보상형 광고 버튼을 광고처럼 꾸미지 않고 준비 상태로 표시한다.
- 퀴즈는 초급 40개, 중급 30개, 고급 30개 총 100개를 유지한다.

## 빠른 반복 작업 규칙

- 작은 문구/CSS/배치 수정은 관련 contract test 1개와 브라우저 화면 확인 1회만 우선 실행한다.
- 퀴즈/보상/미니게임 판정처럼 로직을 바꾸는 경우에만 `test:logic` 전체를 우선 실행한다.
- `lint`와 `build`는 기능 묶음이 끝났거나 사용자가 배포/최종 확인을 요청했을 때 실행한다.
- 브라우저 검증은 현재 이슈를 증명하는 화면 1곳을 기준으로 하고, 전체 플로우 재생은 엔딩/인트로/보상처럼 흐름 자체가 바뀐 경우에만 한다.
- 독립적인 파일 읽기, 검색, 상태 확인은 병렬로 실행한다.
- dev server 재시작은 현재 포트가 응답하지 않을 때만 한다.
