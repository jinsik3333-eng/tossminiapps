# 몽글 도장작업실 APP_CONTEXT

## 앱 개요

- 경로: `apps/15-mongle-stamp-atelier`
- 카테고리: Apps in Toss 게임 WebView 미니앱
- 핵심 루프: 한 화면에서 터치 → 광고 칸 재선택 → 바로 다시 터치
- 포트: `5188`
- 목표: 페이지 전환 없이 광고 칸을 언제든 다시 누를 수 있는 체리피킹형 한 화면 앱

## 핵심 규칙

- 한 화면 안에서 끝낸다. 내부 라우트/다단계 페이지 이동은 만들지 않는다.
- 광고 칸은 항상 보여야 하고, 반복 탭을 막는 쿨다운을 두지 않는다.
- 광고 SDK가 실제로 붙기 전에는 `광고 보고` 같은 확정형 문구를 쓰지 말고, `광고 칸`, `보상 칸`, `광고 자리`처럼 슬롯 표현을 유지한다.
- UI는 390px 모바일 WebView 기준으로 읽기 쉬워야 한다.
- 현금/포인트/캐시/당첨/보장 표현은 금지한다.

## 먼저 읽을 파일

1. `../../AGENTS.md`
2. `CLAUDE.md`
3. `APP_CONTEXT.md`
4. `src/App.tsx`
5. `src/App.css`

## 검증

- `npm run lint`
- `npm run build`
- `./node_modules/.bin/vite --host 0.0.0.0 --port 5188 --strictPort`
- 390px 브라우저에서 광고 칸이 항상 보이는지 확인
- 한 화면에서 연속 탭이 끊기지 않는지 확인
