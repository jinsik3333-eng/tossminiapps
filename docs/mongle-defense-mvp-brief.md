# 몽글 디펜스 MVP Brief

작성일: 2026-05-07
상태: 새 게임 개발 착수안
대상 경로 후보: `apps/08-mongle-defense`

## 한 줄 컨셉

몽글 마을로 내려오는 장난감 몬스터를 30초 동안 막고, 끝날 때마다 몽글 조각과 점수를 얻는 캐주얼 디펜스 게임.

## 왜 이 게임인가

- `몽글 매치 퍼즐` 다음 확장으로 같은 캐릭터 IP를 재사용할 수 있다.
- Toss 인기 게임 관찰에서 키우기/디펜스/스킬형은 매출형 구조에 강하다.
- 3매치보다 액션성이 강해 `한 판 더` 동기가 명확하다.
- 정책 위험이 큰 금융/현금 보상 카피 없이도 광고 보상 루프를 붙이기 쉽다.

## 핵심 플레이 루프

1. 홈에서 오늘의 웨이브와 수집 진행률을 본다.
2. `바로 방어하기`를 눌러 30초 방어전을 시작한다.
3. 화면 위에서 내려오는 몬스터를 탭해 막는다.
4. 콤보가 쌓이면 몽글 방패/구름 폭탄 같은 짧은 스킬을 쓴다.
5. 시간이 끝나거나 마을 HP가 0이 되면 결과 카드가 나온다.
6. 점수와 방어 등급을 확인하고, 랜덤 몽글 조각/방패 스티커를 얻는다.
7. `광고 보고 보너스 웨이브` 또는 `광고 보고 방패 1개 더`로 자연스럽게 재도전한다.

## MVP 화면

### 1. 홈

- 게임명: `몽글 디펜스`
- 한 줄 규칙: `30초 동안 내려오는 몬스터를 막아 몽글 마을을 지켜요.`
- 핵심 CTA: `바로 방어하기`
- 보조 CTA: `도감`, `랭킹`, `설정`
- 유지 요소: 오늘의 웨이브, 7일 방어 기록, 수집 진행률
- 광고 슬롯: 하단 배너 자리

### 2. 프로필/튜토리얼 게이트

- Toss 게임 프로필이 필요한 환경에서는 프로필 생성 전 진행 차단.
- 로컬/브라우저에서는 mock profile fallback.
- 최초 1회 튜토리얼:
  - `다가오는 몬스터를 탭해 막아요.`
  - `콤보를 모으면 방패 스킬을 쓸 수 있어요.`

### 3. 플레이

- 상단 HUD: 남은 시간, 마을 HP, 점수, 콤보
- 중앙: 몬스터가 내려오는 3~4개 lane
- 하단: 스킬 버튼 1개, 광고/힌트 placeholder는 플레이 방해 없이 배치
- 상태: `ready → playing → paused/background → result`
- 저장: 리더보드/광고/백그라운드 전환 대비 현재 시간, HP, 점수, 콤보 저장

### 4. 결과

- 방어 등급: `완벽 방어`, `아슬아슬 방어`, `다음엔 더 잘 막기`
- 점수/콤보/막은 몬스터 수
- 획득: 몽글 조각 또는 방패 스티커
- CTA:
  - `다시 방어하기`
  - `랭킹 보기`
  - `광고 보고 보너스 웨이브`
- 점수 제출은 게임 종료 후 1회만 호출.

## 게임 로직 MVP

- 기본 시간: 30초
- 마을 HP: 5
- lane 수: 3개로 시작, 후반 4개 확장 가능
- 몬스터 타입:
  - common: 1탭 제거
  - shield: 2탭 제거
  - fast: 빠르게 내려옴
  - bonus: 제거 시 추가 점수
- 점수:
  - 제거 기본점수 + 콤보 보너스 + 남은 HP 보너스
- 실패 조건:
  - 몬스터가 하단에 닿으면 HP -1
  - HP 0이면 즉시 종료
- 스킬:
  - 콤보 8 이상에서 `구름 방패` 1회 사용
  - 화면 내 몬스터 일부 제거 또는 2초 감속

## Toss/Game Center 고려

- `getUserKeyForGame`/게임 프로필은 실제 Toss QA에서 확인한다.
- 로컬 MVP에서는 `tossGameCenter.ts` fallback을 유지한다.
- `submitGameCenterLeaderBoardScore({ score })`는 결과 진입 시 playId 기준 1회만 시도한다.
- `openGameCenterLeaderboard()`는 결과/홈 버튼에서만 호출한다.
- 리더보드 복귀 시 플레이 중 상태가 리셋되지 않도록 저장한다.

## 정책/카피 가드

사용 가능:

- `광고 보고 보너스 웨이브`
- `광고 보고 방패 1개 더`
- `광고 보고 오늘 조각 한 번 더 찾기`
- `랭킹에 도전하기`

금지/보류:

- 포인트 지급 약속
- 현금/캐시/돈 받기 표현
- 확정 보상/당첨/추첨 표현
- 금융상품/투자/대출/카드 추천 연결

## 구현 시작 체크리스트

1. `apps/07-mongle-match-puzzle` 또는 최신 game seed 복사.
2. slug/appName/포트/app json 정리: `mongle-defense`.
3. `APP_CONTEXT.md`, `CLAUDE.md` 작성.
4. `src/lib/gameLogic.ts`에 순수 로직 테스트 가능한 형태로 구현.
5. `src/lib/tossGameCenter.ts` fallback 유지.
6. `src/App.tsx`와 `src/App.css`를 390px 기준으로 구현.
7. `npm run format && npm run lint && npm run build`.
8. `.ait` 생성 확인.
9. 모바일 브라우저 QA: 홈/튜토리얼/플레이/결과/랭킹 fallback/광고 CTA.
10. 콘솔 에러 확인.
