# 2026-05-10 Toss 실기기 검수 매트릭스 — 1~6호 일반앱

## 목적

로컬에서 완료된 구현/자산/lint/build 검증 이후, 실제 Toss 앱에서만 확인 가능한 광고·공유·보상 콜백·모바일 밀도 게이트를 앱별로 닫기 위한 수동 검수표다.

## 테스트 전 준비

- Toss 콘솔에서 각 앱 최신 AIT 산출물을 업로드한다.
- 아래 deploymentId는 로컬 빌드 기준 참고값이다. 콘솔 업로드 후 표시되는 버전/빌드와 맞는지 확인한다.
- 테스트 기기는 375~390px 폭에 가까운 실기기를 우선 사용한다.
- 네트워크는 광고 로드가 가능한 상태로 둔다.
- 광고가 Google 반영/No fill로 비어 있을 수 있으므로, 실패 시 콘솔 광고 그룹 상태와 앱 로그/화면을 함께 기록한다.

## 공통 PASS 기준

각 앱에서 아래 7개가 모두 PASS여야 “실기기 검수 완료”로 본다.

1. 첫 화면에서 앱 목적과 시작 행동이 즉시 이해된다.
2. 결과 화면에서 `보상 받기` 영역이 보이고 CTA가 명확하다.
3. 배너 광고 영역이 실제 광고 또는 정상 fallback으로 표시된다.
4. `광고 보고 ...` CTA 클릭 시 리워드 영상 또는 정상 fallback이 동작한다.
5. 광고 완료 후 보상 루틴/카드/처방/결과가 열린다.
6. `친구 추천하고 보상 받기` 클릭 시 contactsViral 또는 정상 공유 fallback이 열린다.
7. 추천 완료 이벤트 후 앱 안 보상 루틴으로 이어진다.
