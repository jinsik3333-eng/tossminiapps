# 토스 미니게임/생성형 앱 기회 리스트

## 작성 배경

실제 Toss 게임 영역 레퍼런스 확인 후, 기존 Apps in Toss 생활/루틴형 미니앱과 토스 미니게임은 사용 양상이 다르다고 정리한다.

- 일반 미니앱: 테스트, 결과카드, 루틴, 단서 수집, 광고 CTA 중심
- 미니게임: 즉시 플레이, 반복 판수, 랭킹/스테이지/토너먼트/상점, 하단 배너/전면/리워드 광고, 커뮤니티/공유 중심

## 인기 게임 순위 기반 관찰

### 실시간 인기 게임

- 정글 매치 퍼즐: 귀여운 동물 3매치 퍼즐
- 한게임 싱글 맞고: 고스톱/맞고류
- 돌돌디: 스킬/방어/액션성 게임
- 애니팡2: 대중적 퍼즐 게임
- 수박 게임: 합치기/성장형 캐주얼 게임

### 내 지갑 채워주는 게임

- 플레이/출석/연속 출석/누적 판수 미션이 붙어 있음
- 1원, 5원, 10원, 20원, 50원 등 소액 리워드가 노출됨
- 우리 앱에서는 현금/포인트 보장 표현을 직접 쓰지 않고, 심사/콘솔에서 허용되는 광고/미션 구조를 확인 후 적용한다.

### 매출로 증명한 인기게임

- 돌돌디
- 레인저스 키우기
- 용사단 키우기
- 비공정기사단
- 머지 해변

해석: 단순 퍼즐뿐 아니라 방치형/키우기/머지/디펜스가 매출형 구조에 강하다.

## 토스 미니게임 후보

### 1. 몽글 매치 퍼즐

- 참고: 정글 매치 퍼즐, 애니팡2
- 장르: 3매치 퍼즐
- 핵심 루프:
  - 같은 캐릭터 3개 매치
  - 이동 횟수 제한
  - 목표 점수/별 3개
  - 스테이지 잠금
  - 광고 보고 추가 이동/힌트
- 장점:
  - 인기 순위 1위 문법과 가장 가까움
  - 연령대가 넓고 심사 리스크 낮음
  - Toss 미니게임 1호 후보로 적합

### 2. 몽글 디펜스

- 참고: 돌돌디, 키우기류
- 장르: 캐주얼 디펜스/스킬 게임
- 핵심 루프:
  - 적이 내려옴
  - 터치/스킬로 방어
  - 스테이지/보스/업그레이드
  - 광고 보고 부활/스킬/보너스 도전
- 장점:
  - 매출형 구조에 유리
  - 캐릭터/IP 확장 가능
- 단점:
  - 3매치보다 밸런싱과 콘텐츠량 부담이 큼

### 3. 푸딩팡 머지

- 참고: 수박 게임, 머지 해변
- 장르: 합치기/성장형 캐주얼
- 핵심 루프:
  - 같은 오브젝트가 만나면 상위 오브젝트로 성장
  - 점수 경쟁
  - 실패 후 즉시 재도전
  - 광고 보고 보조 아이템/이어하기
- 주의:
  - 물리/충돌 구현 난이도가 있을 수 있음

### 4. 안전한 카드/패 맞추기류

- 참고: 한게임 싱글 맞고의 대중성
- 장르: 그림 짝 맞추기/패턴 매칭
- 방향:
  - 고스톱/도박성 직접 모방은 피함
  - 그림패 기억력, 짝 맞추기, 시즌 카드 수집 등 안전한 퍼즐로 변형

## 생성형 AI 앱 후보

### 성경꿈해몽/드림바이블형

- 사용자가 꿈 내용을 입력
- AI가 종교/말씀/위로/해석형 텍스트로 변환
- 일지에 저장
- 다른 사용자 해몽 피드로 커뮤니티화
- 월 무료 횟수 제한 후 광고/구독/유료 크레딧 가능성

### 커뮤니티화 관찰

- `다른 분들의 해몽` 피드가 홈에 노출됨
- 익명/부분 가명으로 꿈 내용과 AI 해석 카드가 공유됨
- 공감/댓글이 붙어 체류시간과 재방문 동기를 만든다
- 생성형 결과물이 개인 콘텐츠에서 끝나지 않고, 공개 피드 콘텐츠로 재활용된다
- 이 구조는 AI 비용을 들인 1회 생성물을 여러 사용자에게 노출해 콘텐츠 효율을 높인다

### 일반화 가능한 생성형 구조

- 꿈 해몽
- 오늘의 기도/위로문
- 타로/심리 편지
- 반려동물 마음 번역
- 육아/연애/직장 고민 위로문

단, 종교/운세/상담형은 표현 수위와 책임 고지, 민감 영역 회피가 중요하다.

## 생성형 앱 수익화 가설

- 무료 횟수 제한: 예) 월 무료 5회
- 광고 보고 추가 생성
- 저장/일지/북마크 기능
- 커뮤니티 피드로 체류시간 증가
- 프리미엄: 긴 해석, 테마별 해석, 이미지 카드, 일지 백업

## 기획 원칙

- 토스 미니게임은 돈/생활비 컨셉을 억지로 붙이지 않는다.
- 인기 게임 순위와 사용 양상을 먼저 본다.
- 룰은 3초 안에 이해되어야 한다.
- 1판은 짧고 반복 가능해야 한다.
- 광고는 게임 루프를 끊기보다 재도전/힌트/추가 스테이지에 붙인다.
- 생성형 앱은 AI 비용이 있으므로 무료 횟수, 광고, 제한 생성, 캐시, 짧은 출력 설계가 필수다.
