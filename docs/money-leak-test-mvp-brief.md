# 돈 새는 구멍 테스트 MVP 구현 지시서

## 목표

`apps/01-money-leak-test`를 기본 스캐폴드 화면에서 실제 테스트형 미니앱으로 전환한다.

## 핵심 컨셉

- 앱명: 돈 새는 구멍 테스트
- 한 줄 후킹: 내 월급은 어디서 새고 있을까? 60초 만에 돈 새는 유형 진단
- 내부 리텐션명: 오늘의 머니루틴

## 사용자 흐름

1. 첫 화면
   - 강한 후킹 문구
   - 60초/8문항/결과 공유 가능 안내
   - 시작 버튼
2. 질문 화면
   - 8문항
   - 진행률 표시
   - 선택지는 3~4개
3. 결과 화면
   - 결과 유형 6개 중 하나
   - 한 줄 진단
   - 대표 누수 패턴
   - 오늘의 처방 1개
   - 상세 처방 보기 버튼 또는 광고 stub
   - 공유 버튼 stub
4. 광고 테스트 화면
   - 기존 인앱광고 테스트 진입은 개발용으로 유지하거나 설정 화면으로 분리

## 결과 유형

- 배달 누수형
- 구독 방치형
- 편의점 새는형
- 야식 합리화형
- 할인 착각형
- 택시 자기합리화형

## 구현 원칙

- React + TDS 모바일 컴포넌트 사용
- 모바일 375~390px에서 읽히는 텍스트 크기
- 과한 금융상품 추천/투자 조언 금지
- 결과는 가볍고 유머러스하되 실제 생활 처방 1개 포함
- 광고는 질문 중간에 끼우지 말고 결과/상세 지점에 배치

## 검증

- `npm run build` 성공
- TypeScript/ESLint 오류 없음
- 광고 미지원 환경에서 앱 기능이 막히지 않음
- 결과 유형 계산이 항상 하나로 귀결됨
