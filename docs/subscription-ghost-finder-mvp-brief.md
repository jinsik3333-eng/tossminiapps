# 3호 앱 MVP 브리프 — 구독료 유령 찾기

작성일: 2026-05-03

## 기본 정보

- 앱명: 구독료 유령 찾기
- 영문명: Subscription Ghost Finder
- 앱 ID: `subscription-ghost-finder`
- 유형: 체크리스트/진단형 미니앱
- 한줄 소개: 안 쓰는데 매달 빠지는 돈, 60초 자동결제 점검

## 핵심 문제

사용자는 OTT, 앱 구독, 쇼핑 멤버십, 클라우드, 음악앱 같은 자동결제를 여러 개 쓰지만 다음 결제일·실사용 여부·중복 여부를 자주 놓친다.

## UX 흐름

1. 홈
   - `이번 달에도 몰래 빠져나간 구독료가 있을지도?`
   - 휴대폰 구독 목록 → 돈 흐름 → 유령 → 해지 전 체크 시각화
   - CTA: `60초 유령 찾기 시작`
2. 질문
   - 8개 자동결제 점검 질문
   - 두 선택지 방식
   - 유령 후보 발견 수를 일러스트에 반영
   - 하단 배너 광고 슬롯
3. 결과
   - `구독료 유령 N마리 발견/잠복`
   - 유령 후보 태그 표시
   - 최근 7회 점검 기록
   - 결과 배너 광고 슬롯
4. 보상 루프
   - CTA: `광고 보고 정리 루틴 받기`
   - 보상형 광고 완료 후 또는 로컬 테스트 fallback으로 구독 정리 3단계 공개
   - 현금/포인트/쿠폰 보상 아님. 생활비 습관용 텍스트 루틴.
5. 공유/재시도
   - 공유 문구: `나는 구독료 유령 N마리...`
   - 다시 점검하기

## 광고 배치

- 질문: 선택지 아래 배너 광고

- 보상형: 결과 카드의 `광고 보고 정리 루틴 받기`
