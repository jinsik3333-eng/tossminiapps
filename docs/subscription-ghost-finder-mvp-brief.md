# 3호 앱 MVP 브리프 — 구독료 유령 찾기

작성일: 2026-05-03

## 기본 정보

- 앱명: 구독료 유령 찾기
- 영문명: Subscription Ghost Finder
- 앱 ID: `subscription-ghost-finder`
- 유형: 체크리스트/진단형 미니앱
- 한줄 소개: 안 쓰는데 매달 빠지는 돈, 60초 구독 점검

## 핵심 문제

사용자는 OTT, 앱 구독, 쇼핑 멤버십, 클라우드, 음악앱 같은 자동결제를 여러 개 쓰지만 다음 결제일·실사용 여부·중복 여부를 자주 놓친다.

## 제품 포지션

- 실제 결제내역, 카드내역, 앱스토어 구독 정보를 자동으로 가져오지 않는다.
- 사용자가 직접 답하는 자가 점검 앱으로 설명한다.
- 금융상품 추천이 아니라 생활비 습관/자동결제 정리 루틴으로 포지셔닝한다.

## UX 흐름

1. 홈
   - `이번 달에도 잊고 있던 구독료가 있을지도?`
   - `토스가 내 구독 목록을 자동으로 읽는 앱은 아니에요.` 안내
   - 휴대폰 구독 목록 → 돈 흐름 → 유령 → 해지 전 체크 시각화
   - CTA: `60초 자가 점검 시작`
2. 질문
   - 8개 구독/자동결제 자가 점검 질문
   - 3선택지 방식: `안 써요/없어요`, `결제 중·잘 씀`, `애매함/안 씀`
   - `구독 정보를 자동으로 가져오지 않아요 · 내 답변으로만 진단` 안내 노출
   - 유령 후보 발견 수를 일러스트에 반영
   - 하단 배너 광고 슬롯
3. 결과
   - `구독료 점검 후보 N개`
   - 유령 후보 태그 표시
   - 최근 7회 점검 기록
   - 결과 배너 광고 슬롯
4. 정리 루틴
   - CTA: `광고 보고 정리 루틴 받기`
   - 보상형 광고 완료 후 또는 로컬 테스트 fallback으로 구독 정리 3단계 공개
   - 현금/포인트/쿠폰 보상 아님. 직접 확인할 때 참고하는 생활비 습관용 텍스트 루틴.
5. 공유/재시도
   - 공유 문구: `나는 구독료 유령 N마리...`
   - 다시 점검하기
