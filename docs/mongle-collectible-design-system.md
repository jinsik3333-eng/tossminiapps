# 몽글 컬렉터블 디자인 시스템

작성일: 2026-05-04
대상 앱: `apps/mongle-match-puzzle`

## 1. 핵심 방향

`몽글`은 점수 아이템이 아니라 100종을 모아가는 콜렉터블 캐릭터다.

방향:
- 한 판마다 랜덤 몽글 1종 획득
- 도감 100종 수집
- 유니크는 전체 드롭의 1%만 출현
- 레어/에픽/유니크는 리더보드 점수 보너스 제공
- 캐릭터 디자인은 과하게 복잡한 몬스터가 아니라 `말랑한 수집 피규어` 톤

## 2. 드롭 확률 MVP

- 커먼: 64%
- 레어: 25%
- 에픽: 10%
- 유니크: 1%

유니크는 5종 이상 존재해도 전체 유니크 카테고리 드롭 확률은 1%로 유지한다.

## 3. 100종 구성 방식

MVP는 `25개 테마 × 4개 변형 = 100종`으로 운영한다.

예시:
- 낮잠 몽글: 말랑/동글/포근/반짝
- 우산 몽글: 말랑/동글/포근/반짝
- 새싹 몽글: 말랑/동글/포근/반짝
- 구름 몽글: 말랑/동글/포근/반짝
- 베리 몽글: 말랑/동글/포근/반짝

이 구조의 장점:
- 실제 이미지 제작 전에도 100종 이름/도감/확률 구현이 가능하다.
- 나중에 이미지 에셋을 붙일 때 테마별 배치가 쉽다.
- 같은 테마 안에서 색/표정/소품만 바꿔도 4종 변형이 자연스럽다.

## 4. 비주얼 톤

추천 톤:
- soft 3D toy
- squishy clay/plush character
- 둥근 몸통 + 작은 팔/다리 + 표정
- 배경 투명 또는 단색 파스텔
- 한국어/영어 텍스트 없음
- 로고/화폐기호/정책 리스크 문구 없음

피해야 할 것:
- 너무 포켓몬처럼 전투형으로 보이는 디자인
- NFT/가챠/현금 보상처럼 느껴지는 보석/코인 과다 사용
- 작은 텍스트가 박힌 카드형 이미지
- 실제 브랜드/캐릭터와 닮은 실루엣

## 6. 희귀도별 디자인 차이

커먼:
- 생활 소품 중심
- 낮은 채도 파스텔
- 표정 단순

레어:
- 반짝 효과/소품 1개 추가
- 색 대비 조금 강하게
- 리더보드 보너스가 있음을 카드에서 표시

에픽:
- 행운/우주/보석 계열
- 후광, 작은 파티클, 더 강한 실루엣

유니크:
- 전체 드롭 1%
- 왕관/오로라/전설 소품
- 단, 현금/코인 보상처럼 보이지 않게 `수집 피규어` 느낌 유지

## 7. 이미지 제작 방식

현재 결정:
- 1차 procedural/MVP 대량 PNG는 사용자 톤 기준을 통과하지 못했으므로 최종 앱 노출에서 제외한다.
- 해당 에셋은 `docs/mongle-legacy-draft-assets/`에 격리한다.
- 앱의 안정 경로는 `/mongles/premium/{001-100}-{series}-{variant}.webp`로 고정한다.
- premium 이미지가 없는 동안은 앱이 CSS placeholder shell을 보여주며, legacy-draft PNG를 fallback으로 쓰지 않는다.

Hermes image2 단계:
- image2로 텍스트 없는 캐릭터 원본 생성
- 내부 제작은 `대표 12종 → 사용자 톤 선택 → 25개 테마 확장 → 100종` 순서
- 사용자에게 보이는 앱 카피는 제작 단계를 노출하지 않고 자연스럽게 `100종 도감`으로 유지
- 앱 내부에는 최적화 WebP를 우선 반영

대표 12종 먼저 만들 이유:
- 사용자가 선호하는 귀여움/덜 유치함/게임스러움 정도를 먼저 맞춘다.
- 100개를 먼저 만들면 톤이 어긋났을 때 수정 비용이 커진다.

상세 아트 디렉션과 100종 프롬프트는 `docs/mongle-premium-art-direction.md`, `docs/mongle-premium-prompt-manifest.json`를 따른다.

## 8. 앱 UI 원칙

- 홈에는 100개 전체를 다 뿌리지 않는다.
- 첫 화면은 `n/100종 수집`과 대표 12칸 미리보기만 보여준다.
- 전체 도감은 별도 화면/모달에서 연다.
- 결과 화면은 획득 캐릭터를 크게 보여준다.
- 유니크 획득 시에는 축하 애니메이션/사운드 후보를 추가한다.

## 9. 100종 프리미엄 3D 에셋 준비 상태

- 최종 노출 예정 위치: `apps/mongle-match-puzzle/public/mongles/premium/`
- 앱 매핑: `/mongles/premium/{001-100}-{series}-{variant}.webp`
- Prompt manifest: `docs/mongle-premium-prompt-manifest.json` 100종 준비 완료
- 1차 MVP 에셋 격리 위치: `docs/mongle-legacy-draft-assets/`
- 앱 연결: 홈 히어로, 도감 미리보기, 결과 획득 카드는 premium 경로를 우선 시도하고 이미지가 없으면 placeholder shell 표시
- 다음 단계: Hermes image2로 대표 12종 톤 확정 후 100종 premium WebP 생성
