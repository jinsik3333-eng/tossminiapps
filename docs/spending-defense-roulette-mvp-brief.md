# 소비 방어 룰렛 MVP / 심사 브리프

## 앱 개요

- 앱명: 소비 방어 룰렛
- 앱 ID: `spending-defense-roulette`
- 영문명: Spending Defense Roulette
- 유형: 데일리 소비 습관 점검 / 5초 선택 루틴
- 핵심 문장: 오늘 흔들리는 소비 순간을 룰렛으로 고르고 5초 선택으로 점검해요.

## 사용자 경험

1. 홈에서 오늘의 소비 함정과 알림/로그인 안내를 확인한다.
2. 룰렛을 돌려 배달비, 택시비, 쇼핑, 구독, 간식 중 하나의 상황을 고른다.
3. 5초 선택 화면에서 방어 선택 또는 함정에 가까운 선택을 탭한다.
4. 결과 화면에서 오늘의 단서와 방어 루틴을 확인한다.
5. 루틴 카드, 30일 기록, 보조 메뉴를 통해 다음 방문 이유를 만든다.

## 1차 리텐션 루프

- 알림 nudge: `알림을 켜면 내일 방어 룰렛을 놓치지 않아요.`
- 로그인 nudge: `로그인하면 30일 방어 기록을 더 안전하게 이어볼 수 있어요.`
- 수집 루프: 방패 3개를 모으면 오늘 기록 저장
- 반복 루프: 내일 다른 소비 함정 예고
- 보조 메뉴: 오늘의 룰렛, 5초 미니 게임, 친구에게 보내기, 기록 보기, 추가 루틴
- 광고 루프: `AD · 광고 보고 추가 방어 카드 열기`, 결과 화면 `광고 보고 루틴 카드 열기`

## 심사 안전 원칙

- 실제 계좌, 카드, 결제 내역, 토스 계정 정보 자동 조회 없음.
- 사용자가 직접 고른 답변 기반의 참고용 생활 소비 습관 콘텐츠.
- 금융상품 추천, 투자 조언, 대출·보험·카드 중개 기능 없음.
- 현금, 포인트, 쿠폰, 캐시백 등 금전성 보상 제공 없음.
- 절약 금액, 수익, 리워드 지급, 당첨, 확률형 보상 보장 표현 없음.
- 광고 이후 열리는 콘텐츠는 텍스트 루틴 카드이며 금전성 보상이 아님.
