# 2호 앱 MVP 브리프: 오늘의 헛돈 방지 퀴즈

## 목표

1호 앱이 일회성 테스트형이라면, 2호 앱은 **매일 들어와서 다른 문제를 푸는 데일리 퀴즈형**으로 만든다. 목적은 재방문, 광고 노출, 공유 유도, 상위 노출 체류 가능성이다.

## 앱 기본 정보

- 앱 이름: 오늘의 헛돈 방지 퀴즈
- 영문/앱 ID 후보: daily-waste-quiz
- 한 줄 설명: 하루 3문제, 오늘 새는 생활비를 막아보는 소비 습관 퀴즈
- 정책 포지션: 금융상품 추천/투자/대출/보험/카드 중개/현금성 리워드 없음. 생활 소비 습관 점검 콘텐츠.

## 핵심 루프

1. 오늘의 퀴즈 입장
2. 3문제 풀기
3. 점수/유형/오늘의 절약 팁 확인
4. 광고 보고 추가 힌트 또는 보너스 문제 열기
5. 오늘의 스탬프 수집
6. 내 결과 공유하기
7. 다음 날 새로운 문제로 재방문

## 데일리 리텐션 장치

- 날짜 기반 오늘의 문제 세트 선택
- 7일 스탬프판
- 오늘 완료 상태 저장
- 연속 방문 문구: `연속 N일째 헛돈 방지 중`
- 보상은 현금/포인트가 아니라 `스탬프`, `절약 팁`, `보너스 문제`, `결과 카드`로 표현

## 수익화 구조

- 퀴즈 완료 후 결과 하단: 배너/전면 광고 후보
- 보너스 문제 열기: 리워드 광고 후보
- 추가 절약 팁 보기: 리워드 광고 후보
- 공유 후 보너스 루틴: 짧은 광고 후보

초기 MVP에서는 1호 앱의 광고 hook/fallback 방식을 재사용한다. 실제 광고그룹 ID는 승인/수익화 설정 후 교체한다.

## Deus/TDS 퀵스타트 기반 화면 패턴

사용자가 직접 화면을 고르지 않도록, 아래 패턴을 기본 선택한다.

1. 시작 화면
   - Toss식 상단 타이틀 + 설명 + CTA 버튼
   - ListHeader/카드형 정보 블록 패턴
   - 문구: `오늘 새는 돈, 3문제로 막아봐`

2. 퀴즈 화면
   - 단일 질문 카드
   - 선택지 리스트 버튼
   - 진행률/문항 수 표시
   - TDS Button/List item 패턴

3. 결과 화면
   - 점수 카드
   - 오늘의 스탬프
   - 절약 팁 카드
   - 공유 CTA

4. 데일리 스탬프 화면
   - 7칸 수집판
   - 오늘 완료 표시
   - 다음 방문 유도

5. 보너스/광고 화면
   - `광고 보고 보너스 문제 열기`
   - 광고 미지원 fallback 제공

## MVP 콘텐츠

- 최소 7일치 문제 세트
- 하루 3문제
- 주제: 배달비, 구독료, 편의점, 택시비, 할인 구매, 야식, 커피, 충동구매
- 정답형이라기보다 생활 습관 선택형/상식형 혼합

## 구현 지침

- `apps/daily-waste-quiz`에 생성
- React + Vite + Apps in Toss Web Framework
- 공식 스캐폴드/TDS/인앱광고 샘플 기반
- 과한 게임/현금 보상 표현 금지
- 모바일 390px 기준 첫 CTA 접힘 없이 보여야 함
- `npm run lint && npm run build` 통과 필수

## 검수 안전 문구

본 서비스는 금융상품 추천, 투자 조언, 대출·보험·카드 중개, 현금성 리워드 제공을 하지 않습니다. 사용자의 일상 소비 습관을 돌아보고 가벼운 재미와 생활 습관 개선을 돕는 퀴즈형 콘텐츠입니다.
