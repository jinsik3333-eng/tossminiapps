# 6호 MVP/심사 브리프 — 영수증 몬스터 잡기

## 앱 개요

- 앱명: 영수증 몬스터 잡기
- 앱 ID: `receipt-monster-catcher`
- 영문명: Receipt Monster Catcher
- 유형: 탭 미니게임 + 소비 습관 자가 점검 + 데일리 루틴
- 핵심 문장: 영수증 몬스터를 탭해서 잡고 오늘의 소비 습관 단서를 확인해요.

## 사용자 흐름

1. 홈에서 오늘의 영수증 몬스터와 수집 현황을 확인한다.
2. `오늘의 몬스터 잡기`를 누르면 탭 게임 화면으로 이동한다.
3. 몬스터를 7번 탭해 HP를 줄이고 포획한다.
4. 결과 화면에서 오늘의 소비 단서와 방어 루틴을 확인한다.
5. 광고 CTA 이후 추가 루틴 카드를 열 수 있다.
6. 잡은 날짜는 30일 기록으로 이어져 재방문 이유를 만든다.

## 리텐션/광고 루프

- 내일 몬스터 예고
- 30일 단서 기록
- 알림/로그인 nudge UI
- 보조 체리피킹 메뉴
- 결과 이후 루틴 카드 CTA
- 하단 배너 광고 placeholder

## 정책 안전 원칙

- 실제 영수증 업로드/인식 없음.
- 실제 계좌, 카드, 결제 내역, 토스 계정 정보 자동 조회 없음.
- 금융상품 추천, 투자 조언, 대출·보험·카드 중개 기능 없음.
- 현금, 포인트, 쿠폰 등 금전성 보상 제공 없음.
- 결과는 사용자가 직접 떠올린 소비 상황 기반의 참고용 생활 루틴 콘텐츠.
