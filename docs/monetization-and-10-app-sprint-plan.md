# 수익화 및 이번 주 10개 앱 스프린트 계획

작성일: 2026-05-02
프로젝트: Apps in Toss 미니앱 10개 출시 실험

## 1. 수익화 원칙

이번 주 목표가 10개 앱이라면 개별 앱을 완벽하게 만들기보다, 같은 엔진/템플릿 위에서 후킹만 다른 미니앱을 빠르게 찍어내야 한다.

우선순위:
1. 인앱 광고(IAA): 가장 빠른 기본 수익화
2. 리워드 광고: 테스트/게임/퀴즈와 궁합 좋음
3. 공유/푸시/재방문 루프: 수익화보다 먼저 트래픽을 만든다
4. IAP/토스페이: 반응 좋은 앱에만 2차 적용
5. 외부 제휴/쿠폰/리드: 정책/운영 리스크 확인 후 일부 앱에만 적용

## 2. 앱별 기본 광고 배치

### 테스트형 앱
예: 돈 새는 구멍 테스트, 소비 MBTI, 월급 도둑 찾기

광고 구조:
- 첫 진입: 광고 없음
- 질문 진행 중: 광고 없음
- 결과 생성 직전 또는 결과 하단: 전면 광고/배너
- 상세 처방 더 보기: 리워드 광고
- 결과 저장/공유 후: 배너

핵심 지표:
- 시작률
- 완료율
- 결과 도달률
- 광고 노출률
- 공유율

### 퀴즈형 앱
예: 헛돈 방지 퀴즈, 생활비 절약 퀴즈

광고 구조:
- 5문제 완료 후 결과 화면: 전면 광고
- 힌트 보기: 리워드 광고
- 오답 해설 더 보기: 리워드 광고
- 랭킹/기록 화면: 배너

핵심 지표:
- 퀴즈 완료율
- 힌트 사용률
- 다음날 재방문율

### 클리커/캐주얼 게임형 앱
예: 돈구멍 막기, 저금통 키우기

광고 구조:
- 게임 중 상단/하단 배너
- 부스터/이어하기/보너스 획득: 리워드 광고
- 일정 플레이 후 전면 광고

핵심 지표:
- 세션 시간
- 리워드 광고 시청률
- 재방문율

### 혜택/큐레이션형 앱
예: 오늘의 공짜 혜택, 구독료 아끼기 체크

광고 구조:
- 리스트 중간 배너
- 상세 페이지 하단 배너
- 고급 필터/모아보기는 추후 IAP 또는 광고 시청 후 제공

핵심 지표:
- 상세 클릭률
- 외부 이동률
- 재방문율

## 3. IAP는 언제 붙일까?

이번 주 10개 앱에는 IAP를 기본 탑재하지 않는다.

이유:
- 심사/정산/상품 설계 복잡도 증가
- 10개 빠른 출시 목표와 충돌
- 어떤 앱이 먹히는지 확인 전에는 결제 UX를 설계해도 낭비 가능성 큼

단, 반응 좋은 앱에는 2차로 붙인다.

IAP 후보:
- 광고 제거
- 프리미엄 결과 리포트
- 추가 테스트팩
- 꾸미기/스킨
- 퀴즈팩
- 클리커 게임 부스터팩

## 4. 이번 주 10개 앱 전략

하나의 공통 템플릿을 만든 뒤 10개 앱을 찍어낸다.

공통 엔진:
- WebView + React
- `npx create-ait-app <app-name>` 기반
- TDS 우선 사용
- 공통 컴포넌트: Hero, QuestionCard, ProgressBar, ResultCard, CTA, AdSlot, ShareButton
- 공통 데이터: `content/*.json`
- 공통 SDK 래퍼: login, anonymousKey, ads, share, analytics, storage

앱 타입 구성:
- 테스트형 5개
- 퀴즈형 3개
- 클리커/미니게임형 1개
- 혜택/체크리스트형 1개

## 5. 10개 앱 후보

1. 돈 새는 구멍 테스트
- 유형: 테스트
- 후킹: 내 월급은 어디서 새고 있을까?
- 수익화: 결과 후 광고, 상세 처방 리워드 광고

2. 월급 도둑 찾기
- 유형: 테스트
- 후킹: 이번 달 내 월급을 훔쳐간 범인은?
- 수익화: 결과 후 광고, 공유 카드

3. 배달비 중독 테스트
- 유형: 테스트
- 후킹: 나는 배달앱에 얼마를 바치고 있을까?
- 수익화: 결과 후 광고, 처방 더보기 광고

4. 구독료 방치 진단
- 유형: 체크/테스트
- 후킹: 안 쓰는데 매달 빠져나가는 돈 찾기
- 수익화: 체크리스트 중간 배너, 결과 후 광고

5. 편의점 헛돈 테스트
- 유형: 테스트
- 후킹: 편의점에서 새는 3천 원의 정체
- 수익화: 결과 후 광고

6. 오늘의 헛돈 방지 퀴즈
- 유형: 퀴즈
- 후킹: 틀리면 오늘도 헛돈 씁니다
- 수익화: 힌트 리워드 광고, 결과 후 광고

7. 절약 상식 OX
- 유형: 퀴즈
- 후킹: 아낀다고 생각했는데 사실 손해?
- 수익화: 힌트/해설 광고

8. 소비 MBTI
- 유형: 테스트
- 후킹: 나는 어떤 소비 인간인가?
- 수익화: 결과 후 광고, 프리미엄 리포트 후보

9. 돈구멍 막기
- 유형: 클리커 게임
- 후킹: 터치해서 줄줄 새는 돈을 막으세요
- 수익화: 배너, 부스터 리워드 광고

10. 오늘의 공짜 혜택 체크
- 유형: 혜택/체크리스트
- 후킹: 오늘 놓치면 아까운 공짜 혜택 5개
- 수익화: 배너, 상세 광고, 추후 제휴

## 6. 개발 일정

Day 1:
- 공통 WebView 템플릿 생성
- SDK 래퍼/광고 슬롯/공유 버튼/분석 이벤트 구조 만들기
- `돈 새는 구멍 테스트` 1호 앱 완성

Day 2:
- 테스트형 템플릿 복제
- 2~5번 앱 데이터만 바꿔서 제작

Day 3:
- 퀴즈형 템플릿 제작
- 6~8번 앱 제작

Day 4:
- 클리커형 간단 게임 제작
- 9번 앱 제작
- 혜택 체크리스트형 제작
- 10번 앱 제작

Day 5:
- 전체 QA
- 앱 아이콘/설명/카테고리/OG 이미지 정리
- 콘솔 등록/검수 제출 준비

## 8. 결론

이번 주 목표는 “돈을 바로 많이 버는 1개 앱”이 아니라, “수익화 가능한 미니앱 10개를 빠르게 출시하고 어떤 후킹이 먹히는지 찾는 것”이다.

초기 수익화는 광고 중심으로 단순화한다.
IAP/제휴는 데이터가 나온 앱에만 2차로 붙인다.
