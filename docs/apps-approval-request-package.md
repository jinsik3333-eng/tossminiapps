# Apps in Toss 승인 요청 패키지 — 1~3호

작성일: 2026-05-03

## 전체 상태

- 1호 `돈 새는 구멍 테스트`: 사용자 확인 기준 이미 승인 요청 접수 완료.
- 2호 `오늘의 헛돈 방어전`: 승인 요청용 카피/번들 준비 대상.
- 3호 `구독료 유령 찾기`: 승인 요청용 카피/번들 준비 대상.
- 배포 API 키는 아직 없음. `ait deploy`는 API 키 입력 단계에서 중단되므로, 현재는 콘솔 수동 업로드/승인 요청 패키지 기준으로 정리한다.

## 공통 심사 안전 원칙

- 금융상품 추천, 투자 조언, 대출·보험·카드 중개 표현 없음.
- 현금, 포인트, 쿠폰, 캐시백 등 금전성 보상 제공 없음.
- 광고 보상은 텍스트 콘텐츠/체크리스트/루틴 열람으로만 설명.
- 절약 금액 보장, 평균 절감액, 수익 창출 표현 사용 금지.
- 생활비 습관, 소비 습관 점검, 구독 자가 점검, 데일리 퀴즈/루틴 중심으로 설명.

- 앱 경로: `apps/money-leak-test`

### 콘솔 입력값

- 앱명: 돈 새는 구멍 테스트
- 앱 ID: `money-leak-test`
- 한줄 소개: 내 월급은 어디서 새고 있을까? 60초 만에 소비 습관을 진단해요.
- 권장 카테고리: 라이프스타일 > 테스트/진단 또는 생산성·습관
- 보조 카테고리: 금융 > 가계부·지출관리 선택 시에도 금융상품 추천이 아닌 생활 소비 습관 진단으로 설명

### 상세 설명

```txt
돈 새는 구멍 테스트는 일상 소비 습관을 가볍게 돌아보는 60초 진단형 미니앱입니다.

배달, 구독, 편의점, 야식, 할인 구매, 택시비처럼 자주 놓치기 쉬운 생활비 패턴을 8개 질문으로 확인하고, 나에게 가까운 소비 누수 유형과 오늘의 작은 정리 루틴을 보여줍니다.

금융상품 추천, 투자 조언, 대출·보험·카드 중개 기능은 포함하지 않습니다. 현금, 포인트, 쿠폰 등 금전성 보상도 제공하지 않습니다.
```

### 심사용 설명

```txt
본 서비스는 사용자의 일상 소비 습관을 돌아보는 테스트형 콘텐츠입니다. 금융상품 추천, 투자·대출·보험·카드 중개, 현금성 리워드 제공 기능은 없습니다. 결과와 루틴은 참고용 생활 습관 콘텐츠이며, 절약 금액을 보장하지 않습니다.
```

### 제출 상태

- 상태: 승인 요청 준비 완료.

### 콘솔 입력값

- 앱명: 오늘의 헛돈 방어전
- 영문명: Daily Waste Defense
- 앱 ID: `daily-waste-quiz`
- 한줄 소개: 매일 5초 퀴즈로 생활비 새는 구멍을 막아보세요.
- 권장 카테고리 1순위: 라이프스타일 > 생산성·습관
- 권장 카테고리 2순위: 교육 > 퀴즈·학습
- 금융 카테고리는 보조로만 고려. 금융상품 추천 앱처럼 보이지 않게 설명.

### 검색 키워드

```txt
절약, 생활비, 소비습관, 헛돈, 지출관리, 가계부, 용돈기입장, 배달비, 구독료, 충동구매, 5초퀴즈, 데일리퀴즈, 절약루틴, 소비퀴즈, 지출퀴즈, 절약습관, 생활비절약, 소비패턴
```

### 상세 설명

```txt
오늘의 헛돈 방어전은 생활비를 갉아먹는 소비 패턴을 매일 5초 퀴즈로 인식하는 데일리 루틴 앱입니다.

매일 하나의 오늘의 괴물이 등장합니다. 배달비, 구독료, 충동쇼핑, 편의점 지출처럼 자주 놓치는 생활비 상황을 짧은 퀴즈로 확인하고, 결과에 따라 방어율과 스탬프를 기록합니다.

퀴즈를 마치면 광고를 통해 오늘의 절약 루틴 3단계를 확인할 수 있습니다. 이 루틴은 현금, 포인트, 쿠폰이 아닌 텍스트 기반 생활 습관 체크리스트입니다.

본 앱은 금융상품 추천, 투자 조언, 대출·보험·카드 중개 기능을 포함하지 않습니다. 절약 금액을 보장하지 않으며, 일상 소비 습관을 가볍게 돌아보는 콘텐츠형 미니앱입니다.
```

### 심사용 설명

```txt
오늘의 헛돈 방어전은 일상 소비 습관을 개선하기 위한 데일리 퀴즈 기반 생활비 습관 미니앱입니다. 금융상품 추천, 투자 권유, 대출·보험·카드 안내를 포함하지 않으며, 현금·포인트·쿠폰 등 금전성 보상을 제공하지 않습니다. 광고 시청 후 열리는 보상은 오늘 테마에 맞는 절약 행동 루틴 3단계 텍스트 콘텐츠입니다. 광고 미시청 시에도 퀴즈, 결과, 스탬프 등 핵심 기능은 이용 가능합니다.
```

### 스크린샷 문구 후보

1. 홈: `오늘의 헛돈 방어전` / `5초 안에 고르면 방어 성공`
2. 퀴즈: `5초 안에 탭!` / `3문제, 각 5초 제한`

```txt
구독료 유령 찾기는 사용자가 직접 답한 내용을 바탕으로 놓치기 쉬운 구독 후보를 확인하는 60초 자가 점검 앱입니다.

영상/OTT, 무료체험, 중복 구독, 앱 삭제 후 미해지, 쇼핑 멤버십, 클라우드 저장공간, 음악/오디오, 다음 결제일처럼 자주 놓치기 쉬운 항목을 8개 질문으로 점검합니다.

이 앱은 실제 결제 내역, 카드 내역, 앱스토어 구독 목록, 토스 계정 정보를 자동으로 조회하지 않습니다. 결과는 입력한 답변을 바탕으로 한 참고용 점검 결과입니다.

점검 결과 후 광고를 확인하면 구독 정리 루틴 3단계를 볼 수 있습니다. 이 루틴은 현금, 포인트, 쿠폰이 아닌 직접 확인할 때 참고할 수 있는 텍스트 체크리스트입니다.

본 앱은 금융상품 추천, 투자 조언, 대출·보험·카드 중개 기능을 포함하지 않으며, 절약 금액을 보장하지 않습니다.
```

### 심사용 설명

```txt
구독료 유령 찾기는 사용자가 직접 선택한 답변을 바탕으로 구독/자동결제 점검 후보를 보여주는 자가 점검형 미니앱입니다. 실제 결제내역, 카드내역, 앱스토어 구독 목록, 토스 계정 정보를 자동 조회하지 않습니다. 금융상품 추천, 투자 조언, 대출·보험·카드 중개 기능을 포함하지 않으며, 현금·포인트·쿠폰 등 금전성 보상을 제공하지 않습니다. 광고 시청 후 열리는 콘텐츠는 구독 정리 3단계 텍스트 루틴입니다.
```

### 스크린샷 문구 후보
