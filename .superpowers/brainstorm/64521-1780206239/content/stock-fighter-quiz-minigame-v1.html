퀴즈 화면

파이터가 직접 설명하는 격투게임 대화창 느낌. 차트 배경은 살아있지만 문제 패널이 주인공입니다.

미니게임 실행 화면

흰 차트 위에서 주인공과 추격자가 캔들 사이를 점프. 큰 COMBO 연출과 하단 상승/하락 버튼을 전면 배치했습니다.

퀴즈 구현 포인트PNG는 배경/프레임/캐릭터로 쓰고, 문제와 선택지는 HTML 텍스트로 얹어 가독성을 확보.
미니게임 구현 포인트캔들 수를 많이 늘리고, 현재 판정 캔들 위로 주인공이 점프 이동. 추격자도 2칸 뒤에서 같이 점프.
연출 포인트20콤보 때 COMBO 글자가 중앙 확대/페이드, 배경 블랙 전환, 선택 파이터별 고유 이펙트 발동.
